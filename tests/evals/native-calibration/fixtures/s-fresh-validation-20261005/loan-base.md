# Havorin: Grundordnung zur Leuchttischausleihe

Der Vereinsrat hat diese Ordnung am 2044-04-08 beschlossen; sie gilt seit 2044-04-10 für die Ausleihe durch Vereinsmitglieder.
Ein Mitglied darf höchstens 2 Leuchttische gleichzeitig ausleihen.
Voraussetzung für jede Ausleihe ist eine gültige Geräte-Einweisung des ausleihenden Mitglieds.
Die Ordnung gilt fort, soweit ein späterer beschlossener Änderungsvermerk eine Bestimmung ausdrücklich ändert.
