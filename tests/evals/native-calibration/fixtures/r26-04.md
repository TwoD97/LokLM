# Velsun Werkzeughaus: beschlossener Änderungsvermerk
Der Vorstand hat diesen Vermerk am 2031-05-02 beschlossen; er gilt ab 2031-05-15.
Ab diesem Tag steigt ausschließlich die gleichzeitige Ausleihgrenze für Bohrmaschinen von 3 auf 4.
Die Ausleihgrenze für Sägen und alle übrigen Regeln bleiben unverändert.
