# Farnel: Protokoll Kupfer
Prüfobjekt FV-8, Baureihe K, Prüfung am 2042-11-07 bei 25 Grad Celsius.
Für FV-8 wird eine zulässige Einspannkraft von höchstens 420 N angegeben.
Das Protokoll ist fachlich gegengezeichnet. Es nennt weder eine Korrektur des Parallelprotokolls noch eine Regel für den Vorrang einer Fassung.
