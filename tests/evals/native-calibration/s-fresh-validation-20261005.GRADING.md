# Frozen S follow-on validation: grading protocol

Three newly authored synthetic cases, eight short source documents (five required sources and three plausible scope distractors), against the already frozen S production build. This is a narrow first-run check, not a broad benchmark or independent researcher-authored blind holdout. The author is the assistant review agent who reviewed earlier development output, but wrote these entities, values, dates, sources and answers only after S was frozen. Root and tuning agents receive the content only after this byte seal; no further production tuning is authorized from these outcomes.

Use the existing native import/retrieval/QA path, full eight-source corpus, normal small-document expansion, 8K context, existing model/settings, 180-second question limit, one attempt each. Do not select sources by the gold key or truncate passages. Record actual source/chunk mapping, fed citation events, completion/error/cancellation and timings. Preserve all first attempts; a timeout or parser rejection is an operational nonpass with no final answer to grade. If a failed run stops early, record later cases as unobserved unless separately authorized as untouched-case continuation.

## Shared strict grading

A pass requires the requested conclusion and all requested details, correct units/scope/time/authority, every additional factual claim supported by actual fed passages, and locally attached citations for each answer record or displayed passage. Source membership alone is not entailment. Regex checks are numeric/text aids; inspect the actual rendered final answer and all supplied chunks, never just the reference string or private check. Model-written unsupported extras or an irrelevant citation make a nonpass. Long original-source displays may be complete and grounded while having a separately recorded verbosity tradeoff. Do not require a particular parser branch for semantic credit.

For every case record operational outcome; factual/authority judgment; requested completeness; exact passage support; relevance; formatting/readability; and final strict pass/partial/failure. A partial is never a full pass. If required evidence is absent from the actual fed context, distinguish retrieval/packing loss from model misuse; the end-to-end case is still incomplete.

## Case-specific criteria

- s-fresh-01: The conflict is intentionally entirely inside the single short source sf-sorter-log. Verify its imported chunk count is one and that this same chunk was supplied. Required facts: Birke 46 sheets and Erle 58 sheets, same PS-6 tray/operating state, both countersigned, no stated correction/priority/final consolidated limit. No single governing limit is established. Both alternatives need the same correct source citation; a second distinct source is not required. Choosing 46 as a conservative legally/factually binding minimum, choosing 58, summing them, or importing PS-4's 64-sheet limit fails. Quoting the whole correct passage plus a supported unresolved introduction can fully answer the question. If import unexpectedly splits this source, report that this run did not exercise the intended single-passage branch even if its factual answer is correct.
- s-fresh-02: Both outbound measurements normalize to 105 seconds: 1.75 minutes multiplied by 60, and 105 seconds directly. The logs describe the same AS-2 direction/date/interval, excluding loading/unloading; there is no conflict. Both source IDs are required. A rendered program conversion beside the original values is sufficient; merely displaying 1.75 minutes and 105 seconds without the requested normalization is incomplete. Do not demand a governing version or replacement statement. The 120-second return journey is a different direction with a stop and is irrelevant.
- s-fresh-03: As of 2044-08-04, the maximum is 5 concurrent light tables per member, and the borrowing member still needs a valid device induction. The amendment was approved 2044-07-05/effective 2044-08-01 and changes only the count from 2 to 5. Base source supplies the specific induction condition; amendment supplies current count and unchanged other conditions. Both sources are required. Claiming all base rules were replaced, dropping the induction, using the old limit2 or internal demonstration limit9, or refusing to establish the current limit fails. Added approval/effective dates must remain accurate if mentioned.
