# LokLM v0.7.4

This maintenance release improves recovery, document workflows, resource
management and dependency security. It also fixes Mac transcription addon loading
and native architecture verification. The v0.7.1, v0.7.2 and v0.7.3 build attempts stopped
before publishing downloads; v0.7.4 replaces those attempts.

- Harden cancellation, vault locking, workspace changes and shutdown against
  late results and stale worker callbacks.
- Fix folder-sync races, document refresh checks and platform-specific
  installation paths.
- Delay indexing's GPU takeover until embedding begins, allowing parsing and
  OCR to finish first.
- Correct quantized KV-cache memory estimates and optional dynamic-K retrieval
  selection; avoid loading unused summary vectors during lexical filtering.
- Keep inline citation numbers and source-menu entries consistent. Show indexed
  text when a PDF's original file has changed.
- Improve model download retries and verified replacement while preserving
  existing files when repair fails.
- Add interrupted-upgrade recovery, stricter archive extraction and stronger
  platform/checksum validation.
- Update vulnerable dependencies and apply tested, pinned backports where an
  appropriate upstream fix is unavailable.
- Build Mac transcription from pinned sources for its native architecture, with
  Metal support and statically linked internal libraries. Verify the addon after
  relocation and again in the extracted delivery archive.
- Rebuild Linux transcription with Vulkan support against the Ubuntu 22.04
  runtime baseline, removing upstream library-path and ABI incompatibilities.
  Declare the Vulkan loader as a Debian package dependency.
- Correct the Mac transcription dependency's binding directory and verify that
  the native addon loads on both Apple Silicon and Intel release builders.
- Inspect the selected Mac binaries without treating bundled inactive Linux or
  Windows transcription assets as Mac executables; unknown layouts remain checked.
- Check only the model library's selected native Mac package, while continuing
  to reject wrong architectures in active binaries and unknown package layouts.
- Extract the Linux `.run` installer into temporary storage and clean up after
  the wizard exits, instead of leaving its payload in the launch directory.
- Run packaged Mac persistence and shutdown checks before tagging, and retain
  bounded diagnostics when shutdown fails.
- Fix a quit race after the vault is already locked: finish cleanup before
  scheduling the final quit on a fresh event-loop turn.
- Restore Intel Mac vector storage by building the missing LanceDB native
  binding from the exact source commit for the installed JavaScript SDK.
  Keep the existing database version and verify native storage operations.

## Validation and limitations

Automated coverage includes application, integration, dependency-security and
native installer checks. Detailed evidence is recorded in
[the bug audit](../research/2026-10-05-bug-audit.md).

**RAG reliability remains unresolved.** The latest isolated 2B development
evaluation passed 1/3 AB cases and 0/8 AR cases under unchanged strict criteria.
Remaining failures include incorrect facts or citations, omitted explanations,
false uncertainty, request errors and formatting violations. Source links and
structured-output checks do not establish factual correctness.

**4 GB GPUs remain constrained.** The default 4B model may fit only partly on the
GPU; a measured conflict-answer check exceeded five minutes without an accepted
answer. The faster 2B diagnostic model has not replaced the production default.
No general speed or answer-quality improvement is claimed.

With the current signing configuration, **Windows artifacts and the macOS DMG
are unsigned**. The **Mac application payloads use ad-hoc signatures**, without
Developer ID signing or notarization. Operating-system trust warnings may appear.

Website download links update after the release workflow verifies and publishes
the platform artifacts and their checksums. This maintenance release does not
represent a passing native RAG quality gate.
