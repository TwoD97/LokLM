# LokLM v0.7.0

LokLM gains a calmer workspace, local planning tools, and coordinated GPU use
for chat and document indexing.

- Add calendar, notes, and todos, with settings to choose which modules appear
  in the navigation.
- Refine startup, model activity, status displays, settings, and document
  workflows, including clearer German and English labels.
- Use the chat LLM for translation and remove the separate translation model
  and sidecar from the application and installers.
- Coordinate model residency so indexing can release chat resources, use the
  GPU, report batch progress, and honor cancellation after the current batch.
- Bound context and GPU memory use on smaller cards; disable automatic
  reranking on 4 GB GPUs and restore chat when needed.
- Improve retrieval, context budgeting, query embedding reuse, and citation
  handling. Preserve completed, interrupted, and failed chat turns consistently.
- Add native GPU workflow checks, synthetic retrieval fixtures, and calibration
  reports with explicit quality limitations.

## Validation and limitations

Native indexing and chat handoff checks passed on a 4 GB GTX 1050 Ti. The latest
indexing run produced 40 vectors from a 20-page PDF in about 30 seconds and
verified live progress and cancellation. Type checking, production builds,
targeted automated tests, and renderer checks passed during development.

Calibration still found incomplete answers and unsupported details in some
source-conflict and uncertainty cases. Experimental source-marker footers remain
disabled by default. The detailed measurements and limitations are recorded in
[the optimization report](../research/2026-09-25-optimization.md).

Installer downloads on the website update after the release workflow uploads
the platform artifacts and records their checksums.
