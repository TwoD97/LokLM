# Abkürzungsverzeichnis

Alphabetisch geordnete Abkürzungen und Akronyme des Handbuchs. Fachliche Erläuterungen
stehen im [Glossar](27_glossary.md); dieses Verzeichnis löst nur die Kürzel auf. Neue
Abkürzungen werden bei Ersterwähnung im Text ausgeschrieben und hier ergänzt
(siehe [STYLE_GUIDE.md](STYLE_GUIDE.md)).

| Abkürzung | Bedeutung |
| --- | --- |
| ADR | Architecture Decision Record |
| AES-256-GCM | Advanced Encryption Standard, 256 Bit, Galois/Counter Mode |
| AP | Arbeitspaket |
| BM25 | Best Matching 25 (lexikalischer Ranking-Algorithmus) |
| CDN | Content Delivery Network |
| CI/CD | Continuous Integration / Continuous Delivery |
| CSP | Content Security Policy |
| CUDA | Compute Unified Device Architecture (NVIDIA-GPU) |
| DEK | Data Encryption Key |
| DMG | Apple Disk Image (macOS-Installerformat) |
| DoD | Definition of Done |
| DSGVO | Datenschutz-Grundverordnung |
| E2E | End-to-End (Test) |
| FTS | Full-Text Search |
| GGUF | GPT-Generated Unified Format (Modell-/Quantisierungsformat) |
| GPU | Graphics Processing Unit |
| HNSW | Hierarchical Navigable Small World (Vektor-Index) |
| IPC | Inter-Process Communication |
| KDF | Key Derivation Function |
| KEK | Key Encryption Key |
| LLM | Large Language Model |
| MCQ | Multiple Choice Question |
| MIT | MIT-Lizenz (permissive Open-Source-Lizenz) |
| MRR | Mean Reciprocal Rank |
| nDCG | normalized Discounted Cumulative Gain |
| NSIS | Nullsoft Scriptable Install System |
| OCR | Optical Character Recognition |
| OSI | Open Source Initiative |
| PR | Pull Request |
| QA | Quality Assurance |
| QLoRA | Quantized Low-Rank Adaptation (Feintuning) |
| RAG | Retrieval-Augmented Generation |
| RRF | Reciprocal Rank Fusion |
| SemVer | Semantic Versioning |
| SMART | Specific, Measurable, Achievable, Relevant, Time-bound (Zielkriterien) |

| WASM | WebAssembly |
